# Superstore Sales Analysis (Task 2)

This repository contains the analysis and visual storytelling deliverables for Task 2 (Data Visualization & Storytelling).
Dataset used: `Superstore_1233_Rows.xlsx` (1233 unique rows).

## Key KPIs
- Total Sales: 1251938.5
- Total Profit: 123507.8
- Total Quantity Sold: 6998
- Unique Customers: 1225
- Number of Orders: 1232

## Files in this folder
- `Superstore_1233_Rows.xlsx` - source dataset
- `task2_outputs/` - generated charts and PDF report
- `task2_report.pdf` - multi-page PDF with visuals and insights

## How to reproduce
1. Open the Excel file in Power BI or Tableau.
2. Create visuals: Sales by Category, Profit by Sub-Category, Monthly Sales Trend, Sales by Region, Discount vs Profit, Top 10 Customers.
3. Add insights and export dashboard as PDF.

## Notes
Charts were generated with matplotlib for quick preview. For the final deliverable, build polished visuals in Tableau or Power BI.
