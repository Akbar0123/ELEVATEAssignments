# Task 5: Exploratory Data Analysis (EDA) – Titanic Dataset

## 📌 Objective
Perform Exploratory Data Analysis to identify patterns, trends, and insights using statistical and visual techniques.

## 📁 Dataset
Titanic Dataset from Kaggle (train.csv)

## 🛠 Tools Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Jupyter Notebook  

## 📈 EDA Steps
1. Loaded dataset  
2. Checked structure using `info()` and `describe()`  
3. Handled missing values  
4. Performed univariate, bivariate, and multivariate analysis  
5. Created visualizations:
   - Histograms  
   - Countplots  
   - Boxplots  
   - Heatmap  
   - Pairplot  
6. Summarized insights

## 📝 Key Insights
- Women had higher survival rates than men  
- 1st-class passengers had better chances of survival  
- Fare is positively correlated with survival  
- Children survived more compared to adults
